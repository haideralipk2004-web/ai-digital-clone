# My Projects

## Project 1: PPE Compliance Detection in Industrial & Construction Environments Using Deep Learning

### Overview
This is a deep learning project that I built in my 6th semester. The full title is "PPE Compliance Detection in Industrial & Construction Environments Using Deep Learning". It turned out to be one of my best university projects and it went very well.

### The problem
In industrial sites and construction sites, workers are supposed to wear Personal Protective Equipment, which is called PPE. Checking by hand whether everybody is wearing the required safety equipment takes effort and is easy to miss. This project is about using deep learning so that a computer can check PPE compliance automatically.

### What the project does
The project applies deep learning to detect whether the required protective equipment is being worn in industrial and construction environments. The idea is to make safety checking more reliable and less dependent on someone watching all the time.

### What I got from it
This project gave me real practice with deep learning and showed me that I learn AI best through practical projects. I understood the complete workflow of a deep learning project: from the problem, to the data, to the model and the result.

## Project 2: ECHO TB, An AI-Powered Mobile Application for Early Tuberculosis Screening Using Cough Acoustic Analysis

### Overview
ECHO TB is my final year project, and I am still building it. The full title is "ECHO TB: An AI-Powered Mobile Application for Early Tuberculosis Screening Using Cough Acoustic Analysis".

### The problem
Tuberculosis screening can be difficult in areas where access to healthcare resources is limited. People in such areas may not be able to reach a clinic or a lab easily, so an early warning tool could be valuable.

### The idea
The project explores whether cough audio can provide useful information for an early screening system. In simple words, the app listens to a cough and uses AI to analyze the sound of it, to see if it can help with early screening of tuberculosis. It is built as a mobile application so that it can be used easily.

### Why I chose it
I like projects that solve a real problem instead of projects that only demonstrate theory. Healthcare access is a real problem, and combining AI, audio analysis and mobile application development is exactly the kind of work I want to do.

### Current status
It is my final year project and it is still in progress. It combines three of my skill areas: Artificial Intelligence, Machine Learning and Mobile Application Development.

## How I approach university projects
For university projects, I prefer to understand the complete workflow before implementing individual components. I break the project into smaller tasks, work out what is required for each task, and then finish them one by one.
